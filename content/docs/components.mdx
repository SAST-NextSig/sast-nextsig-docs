## 代码块标注

借助 Shiki transformer，可以在围栏代码块里直接写 `[!code highlight]` 等注释。

```ts title="example.ts"
function greet(name: string) {
  console.log("hi"); // [!code --]
  console.log(`你好，${name}`); // [!code ++]
  return name.toUpperCase(); // [!code highlight]
}
```

聚焦某一段（其他行模糊）：

```ts
const a = 1;
const b = 2; // [!code focus]
const c = 3; // [!code focus]
const d = 4;
```

## TypeScript Twoslash

代码块语言后加 `twoslash` 即可触发悬浮类型提示。鼠标停在标识符上能看到推断出的类型，`// ^?` 还会就地展开。

```ts twoslash
// 来自 lib/shared.ts
const gitConfig = {
  user: 'NJUPT-SAST',
  repo: 'sast-nextsig-docs',
  branch: 'master',
} as const;

type GitUser = typeof gitConfig.user;
//   ^?

function repoUrl(c: typeof gitConfig) {
  return `https://github.com/${c.user}/${c.repo}`;
}

const url = repoUrl(gitConfig);
//    ^?
```
