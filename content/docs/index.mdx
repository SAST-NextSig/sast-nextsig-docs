## 这个站点是怎么工作的

- 内容写在 [飞书 Wiki](https://njupt-sast.feishu.cn/wiki/space/7625304658956799168) ，由 `pnpm sync:lark` 拉成 MDX。
- 多维表格（分享归档）也作为快照导出，再次 sync 即可刷新。
- 站点本身基于 [Fumadocs](https://fumadocs.dev/) + Next.js 16 App Router + React 19。
- 全文搜索基于 Orama；右下角浮动按钮可基于站内内容向 AI 提问。
